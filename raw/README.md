# raw/ — surowe źródła (TYLKO ODCZYT)

Tu trafiają oryginały: projekty (PDF), oferty, umowy, maile, zdjęcia, notatki. Agent ich nie zmienia (blokada w `.claude/settings.json`).

Każdy plik musi mieć wiersz w [[raw/RAW_INDEX]] zanim zostanie użyty jako źródło.

Podkatalogi: `pdf/`, `projekt/`, `oferty/`, `umowy/`, `korespondencja/`, `kosztorysy/`, `zdjecia/`, `mpzp_i_urzedy/`, `katalogi_producentow/`, `artykuly/`, `youtube_transkrypcje/`.

> W tym repozytorium `raw/` zawiera tylko **fikcyjne pliki .md** udające dokumenty. Swoich prawdziwych źródeł NIE commituj do publicznego repo — patrz `.gitignore` i [[docs/06_FAQ]].
